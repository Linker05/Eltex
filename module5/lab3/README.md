# Практическое задание №3

## Задание

Сделать мигание лампочек на клавиатуре используя ioctl.
Управлением миганием сделать через sysfs.
К примеру если записать в переменную в sysfs значение 1 горит первая лампочка,
2 горит вторая, 4 горит третья и т.д., 7-все.
Значение - это двоичная маска 1(001) 2(010) 7(111).

## Сборка

```bash
make CC=x86_64-linux-gnu-gcc
```

Результаты помещаются в рабочую директорию в папку bin

## Подключение и отключение модуля

Подключение к ядру:

```bash
insmod bin/leds.ko
```

Отключение от ядра:

```bash
rmmod leds
```

## Результат запуска

```bash
echo '7' > /sys/kernel/leds/status
```

Включает мигание светодиводов CAPS, NUM и SCROLL с периодом BLINK_DELAY (2 сек).

```bash
echo '0' > /sys/kernel/leds/status
```

Выключает мигание.

Двоичная маска определена так:

| Кнопка | Двоичная маска |
|:------:|:--------------:|
| CAPS   | 100            |
| NUM    | 010            |
| SCROLL | 001            |
