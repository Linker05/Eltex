# Практическое задание №2

## Задание

Написать модуль ядра для своей версии ядра, который будет обмениваться
информацией с userspace через proc. Адаптировать для своей версии ядра (Структура обработчиков).
Избавиться от харкода (маг чисел) и изолировать переменные модуля (static).

## Сборка

```bash
make CC=x86_64-linux-gnu-gcc
```

Результаты помещаются в рабочую директорию в папку bin

## Подключение и отключение модуля

Подключение к ядру:

```bash
insmod bin/proc.ko
```

Отключение от ядра:

```bash
rmmod proc
```

## Результат запуска

```bash
echo 'testmsg' > /proc/myproc
cat /proc/myproc
```
